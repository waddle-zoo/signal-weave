## Changes to evaluate

- Cards can select aggregate `within_effect` and `mix_effect` from a complete,
  reproducible symmetric rate decomposition. They cannot substitute segment
  contributions, accept a segment selector, or operate on an additive report.
- Generated reports display the typed numeric measurement, comparator, threshold,
  unit and any-segment semantics, rather than only the author's prose label.
- Source-key errors are explained before paid discovery. Schemas distinguish
  source-local keys, analytical comparison keys, and comparison-window names.
- Optional watch/question guidance discourages duplicating source-health checks
  or turning report-writing instructions into unconditional prerequisites.
- Synthetic owner reviewers receive an execution contract separate from owner
  business policy. It names runtime defaults and executable numeric meanings.
  Default confidence/retrieval controls are not invented business thresholds.
  Reviewers must still reject changed business thresholds, routes, populations,
  exclusions, broadened data-gap rules, and misleading numeric bindings.
- Both author agents are reminded that creating or editing a draft is not
  completion; corrections require another bounded review, never an approval bypass.

No confidence floor is lowered. No expert card is preloaded. No business-family
condition is added to production code. Both arms retain the same source access,
owner answers, calculators, citation validation and persistent notes.

## Interpretation

This is a prospective execution of a known-family regression, not a novel holdout
or universal enterprise proof. It still uses synthetic normalized sources and a
simulated owner, not real installations or provider accounts. It cannot establish
real notification delivery, query billing, months-long reliability or causation.

Compare onboarding and subsequent monitoring separately. An accurate result can
still be too difficult or costly to onboard; disclose correction counts and time.
Do not claim dollar savings from illustrative saved-login token estimates, or
speed advantages from missing treatment work. A passing correctness gate does
not itself show comparative product benefit.
